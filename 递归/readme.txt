递归需要递归基

线性递归:每个递归实例最多调用自身一次
数组求和return sum ( A, n - 1 ) + A[n - 1];
减而治之：每次递归问题规模缩减一个常数，直至触及递归基

递归跟踪
递推方程 T(n)=T(n-1)+O(1)=T(n-1)+c1 T(0)=O(1)=c2
        => T(n)=nc1+c2=O(n)
        S(n)=S(n-1)+O(1)  S(0)=O(1)
        => S(n)=O(n)

多递归基
多向递归：多个递归方向可选
求2^n: 1. power2(n)=power2(n-1)<<1  power2(0)=1 O(n)
       2. (n)二进制展开为b1...bk
        2^n= (...((1*2^b1)^2*2^b2)^2....*2^bk)
        power2(nk)=(power2(nk-1)^2)*(2^bk) power2(0)=1
        或power2(n)= 1,n=0
                     power2(n/2向下取整)*2，n为奇数
                     power2(n/2向下取整)，n为偶数
        O(logn)

尾递归消除

多路递归：
    二分递归：
        数组求和return sum ( A, n - 1 ) + A[n - 1]; S(n)=T(n)=O(n)
        return sum ( A, lo, mi ) + sum ( A, mi + 1, hi ); S(n)=O(logn) T(n)=O(n)
    求fib(n):大量递归实例重复
    改进：借助辅助空间记录子问题解，制表or动态规划
        制表：每解决一个子问题，就记录，并在解决问题前查询表格
        动态规划：从递归基出发自下而上递推
